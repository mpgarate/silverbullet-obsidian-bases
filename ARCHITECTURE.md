# Architecture

- `.gitignore`: Ignores installed dependencies and plug source maps generated during builds.
- `LICENSE`: MIT license for open-source distribution.
- `README.md`: Explains how to build, test, and maintain this plug.
- `ARCHITECTURE.md`: Lists each non-dependency project file and its purpose.
- `obsidian-bases.plug.yaml`: SilverBullet plug manifest registering the `.base` document editor and Silversearch index listener.
- `src/silversearch.js`: Silversearch `silversearch:index` event handler for `.base` documents.
- `obsidian-bases.plug.js`: Compiled SilverBullet plug bundle generated by `npm run build` and committed for GitHub-based installation.
- `obsidian-bases.plug.js.map`: Source map generated with the compiled plug bundle.
- `package.json`: Node package metadata, scripts, and SilverBullet build dependency declaration.
- `package-lock.json`: Locked npm dependency graph for reproducible installs.
- `scripts/generate-viewer.mjs`: Generates the browser iframe viewer script from shared core logic.
- `src/core.mjs`: Shared YAML, frontmatter, filter, and table-model logic used by tests and the viewer.
- `src/editor.js`: SilverBullet document editor entrypoint that returns the `.base` viewer iframe HTML.
- `src/generated/viewer-script.js`: Generated browser script embedded by the document editor iframe.
- `test/core.test.mjs`: Node test suite using generated music-themed fixtures for parser and table behavior.
